nothing more.

[ESS reference](./reference/ess/index.mdx) is generated from the specification.

## Build from source

```bash
git clone https://github.com/beyond10x/cortex.git
cd cortex
task check
```

`task check` needs Rust, the [Task runner](https://taskfile.dev/), the `ess` CLI and an `ekr`
binary for the end-to-end tests. It includes `task docs-check`, which fails when the generated
reference pages have fallen behind the specification. `task website` builds this site.
